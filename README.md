# সাধাৰণ জ্ঞান কুইজ (পঞ্চম শ্ৰেণী) — অসমীয়া

দলীয় GK কুইজ web app। কোনো server লাগে নালাগে, GitHub Pages ত চলে।

## খেলৰ নিয়ম
1. দলৰ সংখ্যা (২–১০) আৰু নাম দিয়ক, সময়, নম্বৰ, প্ৰশ্নৰ সংখ্যা ঠিক কৰক।
2. প্ৰতিটো প্ৰশ্ন এটা দলক দিয়া হয় (প্ৰতিবাৰ পাল ঘূৰি যায়)।
3. দলে সময়ৰ ভিতৰত বিকল্প বাছি ল'ব লাগে (শিক্ষকে ক্লিক কৰিব)।
   - শুদ্ধ হ'লে নম্বৰ পায়।
   - ভুল হ'লে বা সময় শেষ হ'লে (বা "পাছ" টিপিলে) একেটা প্ৰশ্ন **পৰৱৰ্তী দললৈ** যায়।
   - সকলো দলে ব্যৰ্থ হ'লে শুদ্ধ উত্তৰ দেখুৱাই পৰৱৰ্তী প্ৰশ্ন।
4. প্ৰথম দলে শুদ্ধ উত্তৰ দিলে "পূৰ্ণ নম্বৰ", পাছ হৈ অহা দলে দিলে "পাছৰ নম্বৰ" (দুয়োটা সেটআপত সলনি কৰিব পাৰি)।

## GitHub Pages ত হোষ্ট কৰা
1. GitHub ত নতুন repository বনাওক।
2. এই ফাইলকেইটা upload কৰক: `index.html`, `style.css`, `app.js`, `questions.js`, `README.md`।
3. Settings → Pages → Source: `Deploy from a branch` → Branch: `main` / `(root)` → Save।
4. ১–২ মিনিটত `https://<আপোনাৰ-নাম>.github.io/<repo>/` ত চলিব।

## প্ৰশ্ন যোগ কৰা
`questions.js` ত এই ফৰ্মেটত লিখক:

```js
{ q: "প্ৰশ্ন", o: ["বিকল্প১","বিকল্প২","বিকল্প৩","বিকল্প৪"], a: 0, c: "বিষয়" },
```
- `a` = শুদ্ধ উত্তৰৰ ক্ৰম (প্ৰথমটো = 0, দ্বিতীয়টো = 1 ...)
- `c` = বিষয়ৰ নাম (অসম, ভাৰত, বিজ্ঞান ইত্যাদি)

বেলেগে JSON ফাইলো (`[ {q,o,a,c}, ... ]`) বনাই app ৰ "নতুন প্ৰশ্ন যোগ কৰক" বুটামেৰে আমদানি কৰিব পাৰি (সেয়া কেৱল সেই browser ত সংৰক্ষিত হয়)। ৫০০০ প্ৰশ্ন সকলোৱে ব্যৱহাৰ কৰিবলৈ `questions.js` ত যোগ কৰাই ভাল।

> ⚠️ প্ৰশ্ন যোগ কৰাৰ আগতে তথ্য শুদ্ধ নে নহয় চাই লওক।
